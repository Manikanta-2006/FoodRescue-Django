Our Mission

Building a World Free of Food Waste

FoodRescue is an intelligent, database-driven logistics engine empowering food donors, charitable relief organizations, and volunteers.

Speed & Freshness

Prepared meals lose quality quickly. Our platform features automated expiry checks, instant matching, and real-time volunteer notifications.

Verified Trust

Receivers are formally verified NGOs and shelters. Donors can confidently hand over meals knowing they reach genuine feeding programs.

Hyperlocal Dispatch

Smart city and neighborhood filtering ensures meals are transported within minimal transit distances, cutting transport emissions.

Academic Project Specification

INT253 Web Development in Python Using Django

This platform demonstrates end-to-end full-stack web engineering following the Model-View-Template (MVT) architecture. It features role-based access control, ORM relational constraints, custom path converters (int, str, slug, and re_path), asynchronous-ready JSON APIs, automated unit tests, and accessible responsive UI design.
